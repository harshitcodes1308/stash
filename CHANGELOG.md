# Changelog

## 0.1.1 — glass UI preview

- Replaced the rectangular shelf presentation with a transparent, rounded material shell and layered highlights.
- Added an adaptive file-tile grid with native icons, hover elevation, selection depth, and missing-file treatment.
- Integrated Smart Actions into the compact glass header and added animated drag-target feedback.
- Added a restrained spring motion system with Reduce Motion support.
- Standardized action panels with material cards and visible form labels.

## 0.1.0 — beta

- Floating local file shelves with menu-bar and global-hotkey access.
- Image conversion/resizing, safe ZIP creation, batch rename, and PDF merging.
- Durable generated-output retention and pinned shelf restoration.
- Pinned shelf frame persistence with safe display clamping.
- Unified regression runner and reproducible app ZIP packaging.

## Distribution status

This beta is locally buildable and ad-hoc signed. Developer ID signing, notarization, final GUI QA, screenshots, and a license selection remain before public release.
