# Stash v0.1.1 — Floating shelf polish

Stash 0.1.1 makes the floating shelf feel smaller, clearer, and more at home on the desktop.

## What’s new

- A refined, neutral glass shelf with a compact empty state and reduced visual bulk.
- Compact adaptive file tiles that make better use of any shelf size you choose.
- Native image thumbnails, cleaner filenames, contextual removal controls, and reliable scrolling for larger collections.
- A dedicated window-drag handle: dragging a file tile now drags the file, not the whole shelf.
- Continued support for multiple shelves, Finder drag-and-drop, pinned shelf restoration, and all existing Smart Actions.

## Included Smart Actions

- Convert or resize images.
- Create a ZIP from selected files and folders.
- Preview and confirm a batch rename.
- Merge selected PDFs in order.

## Before downloading or publishing

This release note is prepared for a future public release. The current 0.1.1 artifact is a local, ad-hoc-signed beta and is not notarized. A Developer ID signature, notarization, final manual QA, a license decision, and populated-shelf screenshots are still required before public distribution.
