# Release screenshots

`stash-empty-shelf.png`, `stash-populated-shelf.png`, and `stash-smart-actions.png` are real 0.1.1 Stash captures supplied for the README. `stash-notch-workspace.png` is a real user-supplied v0.2.0 capture. `notch-silhouette.svg` is a decorative illustration placed above it, not part of the screenshot.

The notch drag sequence has not been recorded. To add a demo, prepare a temporary Finder folder with generic filenames, record dragging a file to the top-center target, show the shelf expanding and receiving it, drag a file back out, and open Smart Actions. Crop to the relevant UI, review every frame for personal content, then add the media here and link it from the README.
