# Stash v0.2.0 — Project FLOW beta

Stash 0.2.0 introduces Project FLOW: a compact, notch-anchored way to collect a file while it is already in motion.

## What’s new

- Drag a file, URL, or text payload toward the top-centre notch target to open a dedicated Stash shelf.
- Use the compact hover control to keep that shelf open while you organise files or run Smart Actions; click it again to return it to the notch.
- Use native Quick Look, Reveal in Finder, and Copy Path from shelf items.
- Choose Notch Mode, automatic collapse, animation intensity, and post-drop behaviour in Stash settings.
- Keep the existing floating shelves, native thumbnails, Smart Actions, drag-and-drop, pinning, and restoration behaviour.
- Use separate notch tabs for different groups of files and pin tabs you want to restore.

## Install

Download `Stash-0.2.0.dmg`, open it, and drag `Stash.app` to the `Applications` shortcut. Stash appears in the menu bar. The global shortcut is Control + Option + Space.

The accompanying `Stash-0.2.0.dmg.sha256` file lets you verify the download with `shasum -a 256 -c Stash-0.2.0.dmg.sha256` from the download folder.

## Beta status

This release is built for macOS 13 or later and is ad-hoc signed. It is not Developer ID signed or notarized, and Gatekeeper rejects it in automated assessment. macOS may block the first launch. It is a GitHub pre-release for testing, not a trusted notarized distribution.
