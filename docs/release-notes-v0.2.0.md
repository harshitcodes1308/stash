# Stash v0.2.0 — Project FLOW beta

Stash 0.2.0 introduces Project FLOW: a compact, notch-anchored way to collect a file while it is already in motion.

## What’s new

- Drag a file, URL, or text payload toward the top-centre notch target to open a dedicated Stash shelf.
- Use the compact hover control to keep that shelf open while you organise files or run Smart Actions; click it again to return it to the notch.
- Use native Quick Look, Reveal in Finder, and Copy Path from shelf items.
- Choose Notch Mode, automatic collapse, animation intensity, and post-drop behaviour in Stash settings.
- Keep the existing floating shelves, native thumbnails, Smart Actions, drag-and-drop, pinning, and restoration behaviour.

## Beta status

This release is built for macOS 13 or later and is ad-hoc signed. It is not Developer ID signed or notarized, so macOS may show a Gatekeeper warning. It is published as a GitHub pre-release for testing.
